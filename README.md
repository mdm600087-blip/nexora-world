# NEXORA — Modern Social UI

A responsive, GitHub Pages-ready static front-end concept for NEXORA.

## Included files
- `index.html` — page structure and demo content
- `style.css` — responsive dark UI, components, and layouts
- `script.js` — navigation, guest browsing, local search, like interactions, share action, and demo auth dialog

## Publish/update on GitHub Pages
1. Download and extract `nexora-modern-github-ready.zip`.
2. Open your repository: `https://github.com/mdm600087-blip/nexora-social`
3. On the repository's main page, choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, and `script.js` from this folder into the repository root. If prompted, confirm replacing the existing files.
5. Commit the changes to the branch/folder configured for GitHub Pages (often `main` and `/root`).
6. Wait a minute or two, then refresh `https://mdm600087-blip.github.io/nexora-social/`. If the old version remains, hard-refresh with Ctrl+Shift+R.

## Important limitations
This project is a **front-end demo**. Visitors can browse without signing in. The login and signup dialog is a visual demo only and does not create accounts or authenticate users. Posts, likes, and counts are sample/local UI data and reset on reload. Real authentication, persistent posts, uploads, chat, moderation, and user profiles require a secure backend/database and appropriate privacy/security work.

## Images and fonts
This demo uses Google Fonts, pravatar.cc, and Unsplash image URLs, so those assets require an internet connection. Replace sample images and add your own branding before production.
